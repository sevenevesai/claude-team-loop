The images are 1600 pixels wide. To change one, edit its SVG and export it again at the size in
its `width` and `height`.

## Alt text

- The loop: "A circle of five stations around a team plugin: Work, Notice, Relay, Review,
  Release. Team members own the first three, the plugin owner the last two. A side panel lists
  what the loop grows: skills, working agreements, gates, hooks, integrations, shared resources."
- What travels: "Session history, project records and local overrides stay on each person's
  machine. After the person approves, counts and task descriptions travel to a shared sheet. The
  owner's review, backlog, plugin source and release follow. A status on every row and a new
  plugin version come back."
- Signals to upgrades: "Eight rows, each mapping a pattern in someone's Claude history to a kind
  of finding and what it becomes: new skill, skill change, working agreement, gate, hook,
  integration, shared resource."
